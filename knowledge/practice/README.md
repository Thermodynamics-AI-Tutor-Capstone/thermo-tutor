## The four things that will actually decide this project

1. **Does [AI Studio](psu-ai-landscape.md) expose an API?** If yes, compliance largely
   dissolves. If no, we're back to vendor agreements and IRB.
2. **What does the [instructor sponsor](faculty-adoption.md) want, fear, and permit?**
   Everything downstream depends on this conversation.
3. **Who actually uses the thing in week ten?** → [equity](equity.md),
   [engagement decay](../concepts/engagement-decay.md)
4. **What are we comparing against?** Students already have free frontier models and a
   required publisher platform. → [incumbent platforms](incumbent-platforms.md)
